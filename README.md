# Portfolio & Blog Platform

A modern, minimalist portfolio and blogging platform built with Next.js 14, featuring a headless CMS architecture with flexible content management capabilities.

## Features

### Content Management
- **Hierarchical Organization**: Top-level categories, subsections, and posts
- **Multiple Display Styles**: Blog posts, project showcases, and title-only lists
- **Rich Content Editor**: Markdown support with live preview
- **Tag System**: Organize and filter content with tags
- **Draft & Publishing**: Control visibility of content before publication

### Admin Dashboard
- **Secure Authentication**: JWT-based authentication system
- **Content Management**: Full CRUD operations for all content types
- **Profile Management**: Customizable bio, social links, and resume
- **Image Upload**: Cloudinary integration for media management
- **Analytics**: View counts and engagement metrics

### Public Interface
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **Clean Typography**: Optimized reading experience
- **Navigation**: Collapsible sidebar with organized content hierarchy
- **Performance**: Static generation with ISR for optimal speed
- **SEO Friendly**: Meta tags and semantic HTML

## Tech Stack

### Core
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: JWT tokens with httpOnly cookies
- **Styling**: Tailwind CSS
